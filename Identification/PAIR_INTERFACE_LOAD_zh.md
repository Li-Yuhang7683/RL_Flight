# 双机体对接面载荷与最小载荷控制模态（design_only）

日期：2026-10-19

## 1. 结论摘要

- **之前的拼接建模没有考虑对接面载荷。** `pair_assembly` 把双机体当作一个
  刚体，只检查净力/净力矩与合运动；两机之间的约束力/力矩从未进入模型。
- 补上自由体分析后，对接面载荷映射的秩为 5（8 路命令 → 6 维接口力/力矩），
  **存在 3 维"对接面零载荷"命令子空间**。它覆盖 **滚转力矩、俯仰力矩、
  竖直力**；**偏航是唯一必然在对接面留下载荷的轴**。
- 推荐的最小载荷控制模态：用零载荷子空间生成滚转/俯仰/总推力，用偏航的
  Pareto 端点（零力或零力矩）补第 4 维；4 轴控制满秩、完全可控。代价是
  姿态角加速度约 7–12 rad/s²（全权限约 23–81 rad/s²），符合"牺牲效率"。
- **如果"完全可控"指 6 自由度任意力/力矩跟踪，则无解**：8 路执行器的
  6 维力/力矩映射秩只有 5（侧拼：`My = 0.05 Fx`；串列：`Mx = 0.05 Fy`），
  与载荷最小化无关，是该执行器拓扑的结构性限制。

## 2. 缺失的模型与自由体方程

对单元 B（与 A 关于对接面中心 J 对称）在悬停点线性化，``F_i``/``M_i`` 为
相对悬停配平的执行器扰动力/力矩（机体系，关于单元自身质心）：

```text
alpha = I_pair^{-1} (M_A + M_B + r_A x F_A + r_B x F_B)
f     = (F_A - F_B)/2 + m (alpha x r_B)
c     = I_unit alpha - M_B - (r_J - r_B) x f
```

``(f, c)`` 是 A 经对接面作用在 B 上的合力与合力矩（关于 J）。第一项说明：
**接口力来自两机的执行器力差与绕拼接体质心的轨道加速度**；第二项说明：
**接口力矩来自单元自身转动惯量需求与执行器力矩之差，以及接口力的力臂**。
对接面结构校核所需的螺栓/法兰载荷可由该合力、合力矩按接口几何分配。

## 3. 零载荷子空间

8 路命令 → 6 维接口载荷的映射 L 的秩为 5，零空间维数 3；其 4 轴控制像
（[Mx, My, Mz, Fz]）秩为 3，覆盖 {Mx, My, Fz}，不覆盖 Mz。

| 轴 | 是否存在零接口载荷命令 |
| --- | --- |
| 滚转 Mx | **是**（精确，线性） |
| 俯仰 My | **是**（精确；共模时非线性也严格为零） |
| 偏航 Mz | **否**（结构性耦合，只能做 Pareto 折中） |
| 竖直力 Fz | **是**（共模下桨+少量格栅补偿） |

侧拼/串列都满足同一结论；差别只是 Mx/My 的零载荷权限随拼接方向互换
（差分推力的长力臂作用在垂直于拼接连线的轴上），这与"轴对称机体下
side/tandem 只是坐标重标"一致。

## 5. 推荐控制模态

### 5.1 分配结构

用 L 的零空间基 `N`（8×3）与 4 轴控制映射 `B4`（[Mx,My,Mz,Fz]）构造：

```text
A_lf  = N (B4 N)^+                (8x3, 零载荷滚转/俯仰/竖直)
A     = [A_lf, a_yaw]             (8x4, 满秩 4)
B4 A  = I4                        （4 轴完全可控）
```

`a_yaw` 取零力矩（共模格栅周向模式，推荐）或零力模式；由接口的
力/力矩许用值决定。两种模式都是共模命令，命令形状见下。
`analysis_json` 中已数值校验 `rank(A)=4` 且 `B4 A = I4`（`allocation_check`）。

### 5.2 命令形状（侧拼 0.075 的四个端点，`[下桨差动, 舵1, 舵2, 舵3]`）

| 模态 | 单元 A | 单元 B | 接口载荷 |
| --- | --- | --- | --- |
| 滚转 Mx（零载荷，取满权限） | [0.029, 1.000, -0.273, -0.273] | [-0.029, 0.697, -0.576, -0.576] | f≈0, c≈0 |
| 俯仰 My（零载荷，取满权限） | [0, 0, -1.000, 1.000] | [0, 0, -1.000, 1.000] | f=0, c=0 |
| 竖直 Fz（零载荷，取满权限；正=机体系向下） | [-0.188, -1, -1, -1] | [-0.188, -1, -1, -1] | f≈0.065 N, c≈0 |
| 偏航 Mz（零力矩，取满权限） | [0, 1, 1, 1] | [0, 1, 1, 1] | f≈0.288 N, c=0 |

要点：

- 滚转的零载荷模态**不是单纯共模**：它用两机下桨差动提供绕拼接体质心的
  轨道力，再用非对称格栅角产生净滚转力矩，两者恰好把接口力和接口力矩
  都抵消。共模滚转只能做到 `c=0`，但会留下约 5.26 N/(N·m) 的接口剪力。
- 俯仰零载荷模态是共模格栅俯仰（两机相同舵角），线性与非线性都严格零载荷。
- 偏航零力矩模态是两机相同的格栅周向模式（共模 swirl）；零力模态需要
  非对称的 swirl/pitch 混合（见 JSON）。
- 零载荷模态会附带侧向力（如滚转约 -4.2 N/(N·m)、俯仰约 20 N/(N·m)），
  当前架构没有侧向位置控制，表现为漂移；可接受但应在仿真中监测。

### 5.3 效率与可控性

- 非线性复核后的零载荷权限：侧拼 0.075 滚转 0.085 N·m（≈12 rad/s²）、
  俯仰 0.018 N·m（≈12 rad/s²）；偏航 0.054–0.060 N·m（≈7 rad/s²）。
  全权限（非线性烟测）分别约 0.58 N·m（81 rad/s²）、0.074 N·m（49 rad/s²）、
  0.178 N·m（23 rad/s²）。即滚转/俯仰约 15–25%、偏航约 30% 的权限，
  但姿态三轴均保持可控。
- 4 轴 `[Mx,My,Mz,Fz]` 满秩；零载荷 3 维 + 偏航 1 维 = 完全可控（4 轴）。
- 6 维力/力矩映射秩 5：侧拼不可达方向为 `-0.0499 Fx + 0.9988 My = 0`
  （即 `My = 0.05 Fx`）；串列为 `Mx = 0.05 Fy`。**任意 6 自由度
  独立跟踪与执行器拓扑矛盾，任何控制模态都无法解决**；需要增加独立的
  侧向力/力矩执行器，或接受这个耦合约束。

## 6. 非线性复核（真实执行器映射，满权限）

| 布局/模态 | 实际净力矩 | 接口力 | 接口力矩 |
| --- | ---: | ---: | ---: |
| 侧拼 0.075 滚转 | 0.0853 N·m | 0.028 N | 0.0020 N·m |
| 侧拼 0.075 俯仰 | 0.0180 N·m | 0.000 N | 0.0000 N·m |
| 侧拼 0.075 竖直 | 实际 ΔFz≈5.9 N（线性目标 8.4） | 0.065 N | 0.0000 N·m |
| 串列 0.075 滚转 | 0.0251 N·m | 0.031 N | 0.0000 N·m |
| 串列 0.075 俯仰 | 0.0855 N·m | 0.032 N | 0.0016 N·m |

满舵角时格栅自衰减/耦合使净力矩低于线性外推，但零载荷抵消仍保持在
0.03 N / 0.002 N·m 量级；俯仰共模严格为零。竖直方向的线性权限 8.4 N
在满舵时实际约 5.9 N（格栅自衰减），但接口载荷仍接近零。偏航没有零载荷解，按 Pareto
选择（满权限时零力矩模式接口力约 0.25–0.29 N，零力模式接口力矩约
0.012–0.014 N·m）。

## 7. 边界与下一步

- design_only、悬停点线性化；刚体对接面；不含结构柔性、螺栓预紧/滑移、
  装配偏差、两机气动互扰与动态冲击。接口合力/力矩是接头细节应力分析的
  输入，不等同于螺栓应力。
- 此前烟测的"安全/收敛"只描述合运动，**不构成对接结构安全证据**。
- 下一步：把 `A = [A_lf, a_yaw]` 接入双机体控制器（替代直接 8 通道反馈），
  在 500 Hz 仿真/审计中逐帧记录 (f,c)，按真实接口许用值选择偏航端点；
  再做接口有限元/台架验证与 HIL。
