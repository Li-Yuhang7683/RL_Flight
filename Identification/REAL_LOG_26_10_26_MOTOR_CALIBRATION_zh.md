# 2026-10-26 电机转速标定与基本可用 LQI 候选

机架身份：`airframe-1`。电机表、极对数推断和 LQI 参数均来自机架1日志。

## 结论

已根据 `log/26.10.26` 两批真机日志完成一次粗略但闭环一致的重新标定，并生成新的
13/19 状态固件候选。新控制器通过日志质量门控、Python/C++ 黄金向量、4 s 和 8 s
四方向极性/回正检查以及 ±roll 舵机反对称检查。

这是一版面向低空受控悬停和后续数据采集的基本可用候选，不是无条件飞行授权。

## 主要原因

两批日志的 `MOT_POLE_COUNT` 均为 `14`。PX4 双向 DShot 用

```text
esc_rpm = 100 * eRPM / (MOT_POLE_COUNT / 2)
```

换算机械转速。若实际电机为 28 磁极，使用 14 会把进入 LQI 的转速放大 2 倍。
未修正日志的上电机平均转速约为 `2166 rad/s`，约为训练集均值
`1075 rad/s` 的 2 倍；按 28 磁极归一后，大多数窗口的输入 z-score 立即恢复到
训练分布内。

同时，`FinalMotorOutputMap` 会在控制器后把两路物理电机命令乘 `0.5`。旧 LQI
内部仍使用映射前的命令和未包含该比例的电机表，因此观察器目标转速与真实响应
不一致。本次标定把最终 0.5 映射包含在“控制器命令 → 实际机械转速”表中。

## 标定参数

- 物理电机磁极数：`28`，启动脚本强制写入 `MOT_POLE_COUNT=28`；
- 最终物理电机输出比例：`0.5`；
- 日志离线校正：旧日志按 `logged_poles / physical_poles = 14 / 28` 归一；
- 电机表点：10 个；
- 电机表（控制器命令域）：

```text
0.00 -> 0.0 rad/s
0.08 -> 0.0
0.20 -> 540.0
0.30 -> 665.0
0.40 -> 790.0
0.50 -> 910.0
0.60 -> 980.0
0.70 -> 1035.0
0.80 -> 1090.0
1.00 -> 1200.0
```

该表是上下电机共享的粗标定中位数。上下桨真实转速仍不同，后续数据足够时应改为
独立的 upper/lower 表。

控制器保持 v2 的积分和舵机参数，仅把 roll/pitch 角速度状态尺度从 `1.0` 收紧到
`0.2`；yaw 保持 `2.0`。辨识增益混合比例保持 `0.8`。

## 使用边界

上机前必须实际核对电机磁极数是否为 28。该数值目前由日志转速、旧静态推力曲线和
训练包线一致性共同推断，不能代替实物计数。若实体不是 28 磁极，必须重新生成电机
表和增益，不能只修改启动参数。

还应先完成：

1. 无桨电机方向和 DShot 遥测检查；
2. 确认 `MOT_POLE_COUNT=28`、`NN_LQI_MODEL=1` 和固件 checksum；
3. 系留/低空悬停、RC 立即接管和输出门控检查；
4. HIL 与实机 shadow；
